RUMAH KEYBOARD - Industrial Redesign Prototype

Prototipe desain ulang halaman utama (storefront) untuk **Rumah Keyboard**, toko perangkat keras _mechanical keyboard_, _custom switches_, _keycaps_, dan perlengkapan _modding_ di Indonesia.

Proyek ini dirancang dengan pndekatan **Mobile-first** dan mengusung estetika **Clean Industrial/Tactile Minimalism** yang mengutamakan tiporgrafi tegas, garis kisi struktural yang presisi, serta keterbacaan spesifikasi teknos produk tanpa gangguan visual.

1. **Konep & Arah Desain**
   Desain ini terinspirasi dari bahasa desain produk inustri klasik _(Dieter Rams, Teenage Engineering)_ serta         merek _boutique mechanical keyboard_ modern _(Mode Design, NovelKeys)_.

2. **Strukture Halaman Utama**
   1. Utility ticker & Sticky Header
      - Top bar
      - Navigasi atas responsif dengan menu mobile drawer, dan indikator keranjang belanja
   2. Asymmetric Split Hero Section
      - Kolom Kiri: Headline berukuran besar, ringkasan kurasi produk, tombol CTA, dan spec strip 3 kolom (Form Factor, PCB Architecture, Authenticity).
      - Kolom Kanan: Showcase produk interaktif dengan tombol pergantian product best seller 
   3. Katalog Utama
      - Dilengkapi tab filter kategori (Semua, Keyboard, Switch, Aksesoris) yang memperbarui daftar produk secara instan.
   3. Workshop & Modding
      - Bagian editorial berlatar gelap (Carbon) yang merinci langkah tuning akustik (Switch Lubing, Stabilizer Tuning, Acoustic Foam).
      - Dilengkapi diagram vektor Exploded View // Gasket Architecture berbasis <svg> murni yang tajam di seluruh resolusi layar.
   4. Trust Strip & Architecture Footer
       - Jaminan keaslian dan pengiriman 4 kolom, diikuti formulir newsletter info restock/group buy, tautan official store (Web, Tokopedia, Shopee), serta jam operasional.

3. Fitur Interaktif Storefront
   1. Slide-Over Cart Drawer: Keranjang belanja geser dari sisi kanan untuk menambah/mengurangi kuantitas item dan menghitung subtotal otomatis.
   2. Instant Search Modal: Pencarian real-time berdasarkan nama produk, kategori, atau tag spesifikasi.

4. Cara Menjalankan Proyek
   Pastikan Node.js (versi 18 atau lebih baru) sudah terpasang di perangkat Anda, lalu ikuti langkah berikut:
   1. Clone repositori atau masuk ke direktori proyek: cd nama-folder-proyek
   2. Instal seluruh dependensi: npm install
   3. Jalankan server pengembangan (development): npm run dev
   4. Buka di browser: Akses alamat lokal yang muncul di terminal (umumnya http://localhost:5173).
